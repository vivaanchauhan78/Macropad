# Custom Macro pad
This is a 3 key macro pad that I made to use as a music controller it has a .91 oled display and a volume knob
I wanted to give a hand at making hardware projects and also wanted a macro pad so instead of buying one I made one! I learned how PCB work! I made schematics of this project and then went on to make my own PCB! I also wanted it too look good so I made a case of it, I went for a boat like design here are some images of the project!
